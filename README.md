✨ Django Animated Login Page

A modern and interactive login page built with Django, HTML, CSS, and JavaScript, featuring a unique flashlight effect and an animated character.

🚀 Overview

This project explores creative web design by combining an interactive visual experience with a Django-based login interface. The flashlight effect reveals the login form, creating an engaging and distinctive user experience.

✨ Features

- 🔦 Interactive flashlight effect
- 🎭 Animated character
- 🔐 Login form interface
- 👁️ Password visibility toggle
- 🌌 Dark, atmospheric visual design
- 📱 Mouse and touch interaction support

🛠️ Technologies

- Backend: Python, Django
- Frontend: HTML5, CSS3, JavaScript
- Static Assets: CSS, JavaScript, and image files

⚙️ Getting Started

1. Clone the repository

git clone YOUR_REPOSITORY_URL
cd Django-Login-Page

2. Install dependencies

pip install -r requirements.txt

3. Apply database migrations

python manage.py migrate

4. Run the development server

python manage.py runserver

Open "http://127.0.0.1:8000/" in your browser. Make sure the login page is configured at the root URL.
